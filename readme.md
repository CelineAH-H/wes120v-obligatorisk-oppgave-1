# Dette er en oblikatorisk oppgave i Wes der oppgaven er å lage en en minimalt nettside med vite og terminalen. 
 

## Formålet med oppgaven

### Målet nå: 
Bli bedre i terminal, og forstår det man skriver i terminalen, ønsker å få nettsiden til å gå. 
### Målet fremover: 
Få nettsiden til å se ut som en faktisk nettside og kunne lære videre 

##
## Les før start
At Node.js og pnpm må være installert om det ikke er instalert vil ikke dette prosjektet kjøre. For at det skal kjøre er det viktig at kommandoen pnpm install benyttes. Utviklingsserveren startes med pnpm dev startes med å bruke kommandoen pnpm dev. Siden åpnes på adressen Vite viser i terminalen skjer kun når kommandoen pnpm dev blir kjørt. Da vil det komme en adresse tilsyne som kan åpnes i nettleseren.
